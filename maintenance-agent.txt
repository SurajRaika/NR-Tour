================================================================================
GIT WORKFLOW
================================================================================

ALWAYS push to 'dev' branch only:

1. Start:
   git checkout dev
   git pull origin dev

2. Make changes to files

3. Push to dev:
   git add .
   git commit -m "blog: Added travel tips post"
   git push origin dev

4. Tell user: "Changes pushed to dev branch for testing"

PUSH TO PRODUCTION (main):
Only when user explicitly says "push to production" or "deploy to main":

   git checkout main
   git pull origin main
   git reset --hard dev
   git push --force origin main
   git checkout dev

Then tell user: "Changes deployed to production (main branch)"
